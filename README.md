# Distributed File Storage System

A production-style, resume-worthy distributed file storage system built with the MERN stack.

## Status: Phase 0 - Project Planning

This project is being built incrementally. See docs/ for architecture decisions as they evolve.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Cache/Coordination: Redis
- Storage: Custom distributed storage-node services
- Containerization: Docker, Docker Compose
